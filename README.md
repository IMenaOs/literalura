<h1>Challenge Literalura</h1>
<hr>
<h2>Este es el desafio Literalura de Alura Latam</h2>
<hr>
<p>Este desafio de backend fue hecho con Java, Spring, Postgres y sus dependencias de Maven como Jackson Databind para el usa de API</p>

<p>Con este programa se puede hacer lo siguiente:</p>
<ul>
  <li>Buscar libros por titulo</li>
  <li>Buscar autor por nombre</li>
  <li>Listar libros registrados</li>
  <li>Listar autores registrados</li>
  <li>Listar libros por idioma</li>
  <li>Listar autores por ano</li>
  <li>Listar top 10 libros mas buscados</li>
  <li>Generar estadisticas</li>
</ul>
<br>
<h2>Recursos usados</h2>
<p>Literalura usa el APi de <a href="https://gutendex.com">https://gutendex.com</a> para obtener la data de los libros y autores. Tambien usamos posgres para almazenar nuestros datos</p>
